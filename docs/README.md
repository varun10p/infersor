# Project Docs

> Provenance: LLM-generated draft. Review and edit by hand before treating this as project authority.

This directory contains planning documents for the personal LLM serving engine project.

## Provenance Convention

Every document should identify how it was produced near the top of the file:

- `Provenance: LLM-generated draft.` for content produced primarily by an LLM.
- `Provenance: Human-authored.` for content written by hand.
- `Provenance: Human-edited from LLM draft.` for content that started from an LLM but was materially revised by hand.

This matters because learning notes, design decisions, benchmarks, and implementation reports should not all carry the same authority. Roadmaps can be LLM-generated. Measurements, final architecture decisions, and lessons learned should be explicitly human-reviewed.
